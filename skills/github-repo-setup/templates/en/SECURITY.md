## Reporting a vulnerability

**Do not open a public issue** to report vulnerabilities.

<!-- TEMPLATE: use the channel the user gave in Phase 1: GitHub private reporting OR e-mail. Delete the unused option. -->
Report privately through [GitHub Security Advisories](https://github.com/{{OWNER}}/{{REPO}}/security/advisories/new).

Report privately by e-mail at [{{SECURITY_EMAIL}}](mailto:{{SECURITY_EMAIL}}).

Please include:

- a description of the vulnerability and its impact;
- steps to reproduce or a proof of concept;
- affected versions or commits.

You will get a reply as soon as the report is reviewed. Please do not disclose the vulnerability publicly until a fix is available.
