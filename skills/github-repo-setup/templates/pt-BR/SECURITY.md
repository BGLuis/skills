## Reportando uma vulnerabilidade

**Não abra uma issue pública** para relatar vulnerabilidades.

<!-- TEMPLATE: use o canal informado pelo usuário na Fase 1: reporte privado do GitHub OU e-mail. Apague a opção não usada. -->
Reporte de forma privada pelo [GitHub Security Advisories](https://github.com/{{OWNER}}/{{REPO}}/security/advisories/new).

Reporte de forma privada pelo e-mail [{{SECURITY_EMAIL}}](mailto:{{SECURITY_EMAIL}}).

Inclua no relato:

- descrição da vulnerabilidade e do impacto;
- passos para reproduzir ou prova de conceito;
- versões ou commits afetados.

Você receberá uma resposta assim que o relato for analisado. Pedimos que a vulnerabilidade não seja divulgada publicamente até que uma correção esteja disponível.
