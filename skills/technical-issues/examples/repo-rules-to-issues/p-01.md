## Goal

The Ready gate sees the Effort of every card, so a triaged issue becomes Ready without a manual move.

## Context

**Evidence:** `tools/project-sync/src/adapters/github/parse/items/mod.rs:88-97` · **Base commit:** `b41c0de`

GraphQL prints a whole Effort as `5.0`, and the parser accepts only an integer token, so every card reads as having no Effort and the gate never passes.

**Reproduction:** `just project-sync --dry-run` on a Project where #40 has Effort 5; the plan leaves #40 in Backlog.

## Scope

**Fix:** parse the number as a float and accept it only when its fractional part is zero, as `parse_priority` already does in `tools/project-sync/src/adapters/github/parse/items/mod.rs:61-70`.
**Acceptance criteria:**
- [ ] A fixture with `"number": 5.0` parses to Effort 5 (`cargo test -p caixa-project-sync parse`).
- [ ] A fixture with `"number": 5.5` is rejected with the item number in the message.

## Depends on

#92, whose parser this changes.

## Definition of Done

- [ ] The acceptance criteria above hold
- [ ] `just check` passes with zero lint exceptions
