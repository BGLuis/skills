**Goal:** an export holds one pool connection for one query, not for 180 thousand.

**Evidence:** https://github.com/acme/shop-api/blob/9f3e21a/src/api/export/handler.ts#L31-L35

Each row calls `getCustomerName(id)`, one query per order: 180 thousand round-trips hold the pool connection (`src/db/pool.ts:8`, `max: 10`) for the 9 s of the export.

**Severity:** High · **Effort:** XS · **Reach:** every export

**Reproduction:** turn on `log_statement = 'all'` in the local Postgres and export a month; the log shows one `SELECT name FROM customers` query per order.

**Fix:** `JOIN` with `customers` in the main query.
**Acceptance criteria:** the same log shows exactly one `SELECT` per export, and an integration test counts the queries of `exportMonth` (`npm test -- export.queries`).

**Not verified:** nothing beyond the epic.
